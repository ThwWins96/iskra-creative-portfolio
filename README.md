# искра — творческое портфолио

Личный архив для работ из разных творческих направлений: 3D и Blender, рисунки, игры, фото и видео, код и другое. Есть публичная галерея, случайная работа на главной, аккаунт, редактирование профиля и огонёк за ежедневную работу.

## Запуск
Требуется Node.js 20.19+ или 22.12+.
В папке проекта запустите `npm install`, затем `npm run dev`.
Конфигурация Supabase задаётся через `.env.local`; проект уже привязан к отдельной базе данных workfolio.

## База
Supabase: https://supabase.com/dashboard/project/cmgetnjnuuetganbjwdm
Схема и RLS-политики находятся в `supabase/migrations`.
